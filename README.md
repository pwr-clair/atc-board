# atc-board (보관용)

2026 예술기술도시 전시장 운영 앱(지킴이 캘린더 · 운영보드)은 **다른 곳으로 이관**되었습니다 (2026-08-30).
이 레포의 GitHub Pages 주소는 더 이상 쓰지 않습니다.

- 현재 위치와 주소는 PWR_MASTER 참조 (공개 레포라 여기에 적지 않음)
- 수정은 이관된 레포에서만 할 것
- 두 페이지는 개장·폐장 체크리스트를 같은 DB 경로(`atc/ex*`)로 공유하므로, `EX_FIXED` 항목을 바꿀 때는 반드시 양쪽을 함께 고칠 것

이 레포에는 근무일지 시트 연동용 Apps Script(`gas-worklog-sync.gs`)만 남깁니다.
